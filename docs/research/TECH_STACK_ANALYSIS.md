# Analyse technique

## Référence observée

- Typographies Inter et Radio Canada.
- Images optimisées et vidéos de fond.
- Navigation responsive, cartes éditoriales, accordéons et sections alternées.
- Composition centrée avec larges marges et surfaces presque sans ombre.

## Équivalents Koto

- Next.js 16 App Router et React 19.
- TypeScript strict.
- CSS global existant, tokens centralisés dans `koto.css`.
- `next/image` pour les images locales et WebP.
- Lucide React pour les icônes d’interface.
- Simple Icons pour les marques d’intégration.
- Composants clients limités à la navigation et aux interactions vidéo/révélation.

## Adaptation

La structure et le rythme visuel suivent la référence, mais la marque, le contenu, les visuels produit et les affirmations sont propres à Koto. Les témoignages, logos clients et résultats commerciaux de Maki ne sont pas reproduits.
